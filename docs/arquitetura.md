# Arquitetura do Projeto

## Visão Geral
Sistema de Gestão de Células desenvolvido em PHP Vanilla utilizando o padrão MVC (Model-View-Controller).

## Banco de Dados
PostgreSQL com modelo multi-tenant para garantir o isolamento e segurança dos dados de diferentes organizações.

## Ambiente
Docker utilizado para orquestrar os serviços e padronizar a execução.
